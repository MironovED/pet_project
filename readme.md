### Название проекта: 
Библиотека песен для игры под гитару

### Что в себя включает:
Тексты песен, ссылки на песни в сети интернет.

Есть раздел с аккордами отдельно (в виде картинки с зажатыми струнами).

### Что из себя представляет приложение:
*Клиентское приложение - интерфейс на swing-е и веб-интерфейс*

* При открытии приложения необходимо будет пройти авторизацию
* Можно добавить новую песню (текст, ссылку, аккорды) и аккорды (отдельный раздел с аккордами).
* Есть возможность удалить песню и аккорд.
* Когда я выбираю конкретную песню из имеющегося списка она отображается на экране:
аккорды, текст песни, в конце ссылка в яндекс музыку. 

Сервер - служит базой данных для песен и аккордов*

### Как будет происходить взаимодействие:
Изначально обмен данными будет происходить через Socket.



## Как запустить?

1. Запускаем класс AppServer
2. Запускаем класс AppClient
